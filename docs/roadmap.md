# ARYA Roadmap

This roadmap outlines a multi-phase plan to build ARYA as a long-term, safety-first personal AI operating system. Each phase focuses on a distinct capability set and measurable outcomes.

---

## Phase 1: Conversation + Memory
- Objectives
  - Deliver robust conversational interface and reliable memory persistence.
- Features
  - Natural-language dialog interface (text-first).
  - Short-term session context and structured long-term memory store.
  - Notes, bookmarks, and manual tagging workflows.
- Success Metrics
  - Stable storage and retrieval of user notes across sessions.
  - 80% user satisfaction in basic recall tasks.

---

## Phase 2: Goals + Tasks
- Objectives
  - Add goal management, task breakdown, and scheduling primitives.
- Features
  - Goal creation, hierarchical decomposition, and task templates.
  - Task state tracking, reminders, and prioritization helpers.
- Success Metrics
  - Users successfully create and complete multi-step goals.
  - Task completion rate improvements versus baseline.

---

## Phase 3: Research + Knowledge
- Objectives
  - Provide research workflows and knowledge synthesis tailored to user ambitions.
- Features
  - Source ingestion (web, PDFs, notes), citation tracking, and summarization.
  - Persistent knowledge graphs and topic-specific dossiers.
- Success Metrics
  - Useful synthesized briefs produced within user-requested timeframes.
  - High relevance scores from users on synthesized research.

---

## Phase 4: Computer Actions
- Objectives
  - Enable ARYA to perform safe, auditable actions on behalf of the user.
- Features
  - Integrations with calendar, email, task managers, and browser automation (opt-in).
  - Action sandboxing, dry-run previews, and approval flows.
- Success Metrics
  - Successful completion of low-risk automated tasks with explicit user consent.
  - Clear audit trail and rollback in >95% of action cases.

---

## Phase 5: Voice Assistant
- Objectives
  - Add natural voice interaction channels while maintaining privacy.
- Features
  - Local-first wake-phrase handling, speech-to-text, and voice command mapping.
  - Voice-driven workflows for quick capture and task delegation.
- Success Metrics
  - Low false-activation rate and user satisfaction with voice workflows.

---

## Phase 6: Vision + Screen Understanding
- Objectives
  - Extend ARYA with visual comprehension to assist with screen-based workflows.
- Features
  - OCR, screenshot understanding, and semantic screen analysis.
  - Assistive overlays and action suggestions based on visual context.
- Success Metrics
  - Accurate extraction of relevant information from screenshots.
  - User trials demonstrating reduced task friction.

---

## Phase 7: Autonomous Agents
- Objectives
  - Carefully introduce constrained autonomous agents for long-running tasks.
- Features
  - Agent templates with explicitly scoped responsibilities and safety checks.
  - Monitoring, human-in-the-loop checkpoints, and resource constraints.
- Success Metrics
  - Agents complete delegated workflows without unexpected side effects.
  - Monitoring signals detect anomalies and halt agents when required.

---

Each phase includes a prioritised set of design reviews, privacy threat models, and user testing cycles before wider release.
